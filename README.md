# PRK WhatBuffs & Item Database

`!whatbuffs` for **Project Rubi-Ka** — the classic bot command, rebuilt as a tool that runs in your browser. PRK (Anarchy Online 18.4) doesn't have the live-server chat bots, so this fills the gap, with data extracted directly from the PRK game client.

**Use it here: https://rad-talent.github.io/PRK-Items/**

Or download `PRK-Items.html` and open it in any browser — everything is in the one file and it works offline.

## WhatBuffs
Pick a skill (Pistol, Treatment, Nano Programming, anything) and get every item and nano program that buffs it — grouped by equipment slot with counts, just like the bots on live:

> Here are the 350 items and 113 nano programs that buff Pistol:
> Weapon (14) &bull; HUD (19) &bull; Utils (8) &bull; Head (40) &bull; ...

Click a slot to expand it, click an item to see its full details.

## Item Search
Search 119,000+ items by name and view full stats in an in-game style info window — requirements, modifiers, damage, the works. Click QL buttons to compare breakpoint variants, or type any QL to see interpolated stats.
